# 4.4 Pruebas exploratorias

## Objetivo

Explorar manualmente el Sistema de Gestión de Citas Médicas — Clínica Angry para comprobar el comportamiento de sus funciones principales e identificar posibles errores que no se hayan detectado mediante las pruebas automatizadas.

## Sesión 01 — Inicio de sesión

- **Funcionalidad evaluada:** Inicio de sesión.
- **Objetivo:** Comprobar la respuesta del sistema ante diferentes credenciales.
- **Acciones realizadas:** Probar el inicio de sesión con campos vacíos, contraseña incorrecta y credenciales válidas.
- **Resultado observado:** Pendiente de exploración manual.
- **Hallazgos:** Pendiente de registrar.
- **Evidencias:** Pendiente de adjuntar.

## Sesión 02 — Reserva de citas

- **Funcionalidad evaluada:** Agendamiento de citas médicas.
- **Objetivo:** Comprobar la navegación y las validaciones durante la reserva.
- **Acciones realizadas:** Intentar avanzar sin seleccionar especialidad y médico, seleccionar opciones disponibles, avanzar entre pasos y revisar el comportamiento cuando no hay horarios.
- **Resultado observado:** Pendiente de exploración manual.
- **Hallazgos:** Pendiente de registrar.
- **Evidencias:** Pendiente de adjuntar.

## Sesión 03 — Historial de citas

- **Funcionalidad evaluada:** Sección Mis citas.
- **Objetivo:** Revisar la visualización del historial y el cierre de sesión.
- **Acciones realizadas:** Abrir Mis citas, revisar las columnas mostradas y cerrar sesión.
- **Resultado observado:** Pendiente de exploración manual.
- **Hallazgos:** Pendiente de registrar.
- **Evidencias:** Pendiente de adjuntar.

## Conclusión

Las pruebas exploratorias complementan las pruebas automatizadas mediante la interacción manual con las funcionalidades principales. Los resultados definitivos se registrarán después de realizar cada sesión y revisar las evidencias correspondientes.
